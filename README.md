# Particle System Exercise
A starter project for exploring creating particle systems in MonoGame.

The associated video tutorial can be found at [https://youtu.be/dLz6556Xkso](https://youtu.be/dLz6556Xkso)

This tutorial was created for the CIS 580 - Foundations of Game Programming course offered by the [Department of Computer Science](https://cs.ksu.edu) at [Kansas State University](https://ksu.edu)
